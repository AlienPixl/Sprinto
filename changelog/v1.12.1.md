## Bug Fixes

- **Sprinto no longer stays down after a crash or a server restart.** The app container in `docker-compose.yml` used `restart: "no"`, so a reboot of the host or the Docker daemon left the database running but the app stopped until someone started it by hand. It now uses `restart: unless-stopped`, the same as the bundled PostgreSQL service. A configuration error in `.env` still stops startup with a clear message in `docker compose logs app`; Docker simply retries until it is fixed, and `docker compose stop app` halts the retries.
