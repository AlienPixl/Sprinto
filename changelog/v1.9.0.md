## Features

- Jira import rules now support **groups** — the equivalent of parentheses. A group holds its own conditions and AND/OR connectors and is resolved before its result joins the rules around it, so *Status NOT IN (Done) AND (Labels IN (dor) OR Labels IN (auto))* is finally expressible. Groups nest up to five levels deep, in both the room import panel and the admin default filters.

- New **Evaluates as** line under the rules reads the whole set back as one expression, with statuses shown by name instead of internal ID.

## Bug Fixes

- Import rules had no grouping, so *A AND B OR C* imported every issue matching C regardless of its state. A group now binds the intended part of a rule together.

- Opening **Import from Jira** fetched boards, sprints, statuses and labels all at once and auto-selected the first board — enough to exhaust the Jira API rate limit when several people planned at the same time. Each list now loads when its own picker is opened, once per session, and no board is pre-selected.

## Improvements

- The room and admin filter editors are now one shared editor instead of two copies kept in step by hand.

- A group that loses its last condition is removed automatically, together with the connector that joined it to its neighbour.

- Jira option lists are cached on the server — boards, statuses and labels for ten minutes, sprints for two, worklog link types for thirty — and simultaneous openers share a single request. Issue data is never cached, so estimates and statuses always read live. Changing the Jira connection clears the cache.

- Jira requests are limited per user by how expensive they are, and going over a limit now returns a clear "Too many requests" message instead of an unexplained failure.

- The worklog **Issue** and **User** pickers search on Enter or the search button rather than on every keystroke, and Enter no longer submits the whole report by accident.

- **Preview** and **Import** carry a short cooldown, five seconds and three, counted down in the button itself so a second click cannot fire a duplicate import.

- Lazy-loaded dropdowns show a spinner while their options load and an error with **Try again** when the request fails, instead of an empty list.

- The search box in the Jira pickers no longer towers over the rows beneath it, and more of the list is visible before it scrolls.
