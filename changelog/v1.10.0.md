## Features

- New **Find in Jira** panel next to the queue: search any Jira issue by key or summary, tick the ones you want and add them in one go. Import rules are deliberately ignored, so an issue from another sprint or one that fails the filters can still be estimated.

- Issues added this way are full Jira issues, not plain text — **Send to Jira**, story points and original estimate writeback all work on them exactly as on a board import.

- Manual entry moved into its own **Add manually** panel with an optional *Close after adding*. Leave it off to type several issues in a row without reopening the panel; the choice is remembered.

## Improvements

- The queue toolbar now holds only *Add manually*, *Find in Jira* and the filter and sort controls, so the issue list gets the full height of the panel.

- A hand-picked Jira issue carries no board or sprint scope, so re-running a board import never removes it. Duplicates are still recognised — an issue already in the queue, in play or already estimated is shown as *In queue* instead of being added twice.

- Searching runs on Enter or the search button only, and repeating the same query does nothing, so browsing for an issue cannot exhaust the Jira API rate limit.

- Adding issues returns straight to the queue with a short summary under the list. A failed add keeps the panel open with the reason instead of closing silently.
