## Features

- **A failed Jira send (estimate, assignee, or report) is no longer silent.** The Send to Jira panel now covers itself with an overlay showing why the send failed, with a 5-second countdown bar before it clears — shown only to whoever just clicked Send, with no badge left behind on the issue.

- **"Return to queue" is now "Skip issue".** Instead of silently reinserting the issue at the top of the waiting queue — which made it easy to vote the same issue twice without noticing — it moves to a separate Skipped group. A skipped issue can still be picked back up for voting, edited or deleted like any other queued issue, and its timeline now records who skipped it and when. The queue filter is a multi-select (Waiting/Skipped/Completed, defaulting to Waiting + Skipped) built on the same filter dropdown already used by the dashboard's Status/Category filters.

- **The dashboard's Category filter is now multi-select**, matching the Status filter next to it — pick any number of categories instead of just one. "All" now leads both filters, and every chip label (Open, Voting, Revealed, Closed, All) is capitalized.

- **The room action menu is reorganized into clearer groups.** Next issue, Reveal cards, Skip issue and History now lead the panel, followed by the Jira actions, then Room settings and Close room — each group set off by a divider instead of one long unbroken list.

## Bug Fixes

- **The Send to Jira panel used to close itself the instant you clicked Send**, before the request even finished, so a failed send showed nothing at all. The panel now stays open until the attempt actually completes.

- **The permission to close a room was impossible to find.** It was labeled "End Round" under Poker Voting in the role editor, which gave no hint that it was actually the right to close a room. It is now called "Close Room" and lives under Room Management, where an admin granting room permissions would look for it.

- **The room screen button and its confirmation dialog now say "Close room"** instead of "Close poker", matching what the action actually does: it closes the whole room, not just the current round.

- **A failed Jira write-back (estimate, assignee, or report) left no trace.** When Jira rejected the request or was unreachable, the sprint audit log stayed empty, making the failure invisible. Failed write-backs are now recorded in the audit log alongside successful ones.

- **Checking an issue in "Find in Jira" and then searching again lost the checkmark.** Selections now survive a new search, and a "N selected" pill lets you see and toggle between the full selection and the current results.

- **"Next issue" didn't always open its Jira tab**, even with auto-open enabled, while starting the same issue by hand from the queue list worked. The browser's popup blocker was silently dropping a tab opened too long after the click; starting a queued issue now opens it immediately, so it's no longer a race.

- **The last import rule couldn't be removed**, in both the room and the admin default filters, even though clearing every rule is the only way to say "import the whole sprint". The rule list can now be emptied out completely, and shows a clear "No rules — every issue in the import scope will be imported" message when it is.
