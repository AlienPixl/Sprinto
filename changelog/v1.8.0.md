## Improvements

- The Jira import filter **Status** and **Labels** pickers now include a search box. Open a picker and start typing to filter the list to matching entries — helpful when a Jira instance has a long list of statuses or labels. The search is available in both a room's Import from Jira rules and in Settings → Integrations → Jira default import filters, and clears each time the picker is reopened.
